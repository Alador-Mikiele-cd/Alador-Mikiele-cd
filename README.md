What I'm Building
🌿 OpenShelf

A free platform for Ethiopian students to share textbooks, past exams, notes, and get help from teachers and peers across the country.


Built the first version in high school using HTML, CSS, and JavaScript
Tested with real students and teachers from Grade 9 through Grade 11
Piloted at Mekelle University CNCS campus through the STAM program
Currently rebuilding as a full-stack application

Stack: Next.js · Tailwind CSS · Node.js · Express · MongoDB
